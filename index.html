  • Wrote a GitHub Actions workflow that rebuilds and redeploys on every push to main

  • Kept the repository private, because a self-hosted runner executes code from the repo

Built with Git, GitHub Actions, Docker, Nginx

What went wrong, and how I fixed it

  • SSH warned that the host key had changed after I rebuilt the VM. I confirmed it was my own machine, then removed the old fingerprint with ssh-keygen -R.
  • The VM installer skipped the SSH server. I installed OpenSSH myself and enabled it with systemctl.
  • I first downloaded the Windows build of the GitHub runner into a Linux VM, which failed. Choosing the Linux build fixed it.
  • Docker could not connect to its engine on my laptop. I learned the command and the engine are separate, and ran the build inside the VM instead.
